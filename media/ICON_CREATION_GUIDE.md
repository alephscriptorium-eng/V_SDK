# Arrakis Theater Icon

Since VS Code requires PNG format for extension icons, we need to convert our SVG icon to PNG.

## Current Icon Design
- Hacker-style green color scheme (#00ff41)
- Emblema hacker: upward arrow in circle
- Theater elements (🎭) in corners
- Dark background (#0a0a0a)
- 128x128 pixels

## Manual Creation Instructions
To create the PNG icon manually:

1. Open the SVG file `arrakis-theater-icon-simple.svg` in any SVG editor or browser
2. Take a screenshot or export as PNG at 128x128 resolution
3. Save as `arrakis-theater-icon.png`

Alternatively, use online SVG to PNG converters:
- https://convertio.co/svg-png/
- https://www.svgtopng.com/
- https://cloudconvert.com/svg-to-png
