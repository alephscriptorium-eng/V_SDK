
# 🚀 Guía Rápida de Desarrollo Local

Esta es una guía rápida para desarrolladores que quieren probar la extensión MCP VS Code en local.

## ⚡ Inicio Rápido

### Opción 1: Script Automatizado (Recomendado)

**Windows (PowerShell):**
```powershell
.\build-and-install.ps1
```

**Linux/Mac (Bash):**
```bash
chmod +x build-and-install.sh
./build-and-install.sh
```

### Opción 2: Comandos npm

```bash
# Desarrollo completo (compilar, empaquetar e instalar)
npm run deploy:local

# Solo compilar e instalar (más rápido para cambios pequeños)
npm run dev:quick

# Solo empaquetar
npm run package:local
```

### Opción 3: Desarrollo en modo Debug

1. Abrir VS Code en la carpeta del proyecto
2. Presionar **F5** (inicia Extension Development Host)
3. Probar cambios en tiempo real

## 🧪 Verificación Rápida

Después de instalar, verificar que funciona:

1. **Comandos básicos**: `Ctrl+Shift+P` → buscar "MCP Manager"
2. **Panel lateral**: Buscar icono "MCP Socket Manager"
3. **Chat participant**: `@mcp hello` (requiere GitHub Copilot)
4. **Comandos slash**: `@mcp /config`, `@mcp /troubleshoot`

## 📁 Estructura de Archivos

```
mcp-vscode-ext/
├── src/
│   ├── extension.ts              # Punto de entrada
│   ├── mcpChatParticipant.ts     # Nueva funcionalidad de chat
│   └── core/
│       └── extensionBootstrap.ts # Inicialización
├── package.json                  # Configuración y scripts
├── MANUAL_INSTALACION_LOCAL.md   # Manual completo
├── build-and-install.sh          # Script Linux/Mac
└── build-and-install.ps1         # Script Windows
```

## 🔧 Scripts Disponibles

| Comando | Descripción |
|---------|-------------|
| `npm run dev:quick` | Compilar e instalar rápido |
| `npm run deploy:local` | Proceso completo de instalación |
| `npm run build:local` | Solo compilar y empaquetar |
| `npm run package:local` | Solo crear archivo .vsix |
| `npm run install:local` | Solo instalar extension |
| `npm run uninstall:local` | Desinstalar extensión |

## 🚨 Solución Rápida de Problemas

**Error de compilación:**
```bash
rm -rf out/ && npm run compile
```

**Extensión no aparece:**
```bash
npm run uninstall:local && npm run deploy:local
```

**Chat participant no funciona:**
- Verificar que GitHub Copilot esté instalado y activo
- Verificar VS Code versión 1.74.0 o superior

**Errores en Developer Tools:**
- `F12` → Console → buscar errores en rojo

## 💡 Tips de Desarrollo

- **Desarrollo activo**: Usar F5 para modo debug
- **Cambios pequeños**: `npm run dev:quick`
- **Testing**: `npm test` antes de empaquetar
- **Logs**: Ver en Output → "AlephScript - All Logs"
